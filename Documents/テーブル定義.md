# テーブル定義 - mimamori

データはすべて SQLite（`modernc.org/sqlite`）で管理します。外部のデータベースサーバーは使いません。データベースは用途ごとに次の 3 種類のファイルに分かれます。

| 種類 | ファイル | 置き場所 | マイグレーション | 内容 |
| --- | --- | --- | --- | --- |
| セントラル管理用 DB | `central.db` | データディレクトリ（既定は実行ファイルと同じディレクトリの `data/`。実行ファイルの場所を求められない場合はカレントディレクトリの `data/`） | `app/migrations/central` | アカウント、セッション、確認コード、確認済みのブラウザ、トークン、監視ルール、テンプレート、抑止条件、履歴、証明書、通知、監視対象の一覧、設定と内部の状態 |
| 監視対象ごとの DB | `targets/agent-<agents.id>.db` | データディレクトリの `targets/` | `app/migrations/agentdb` | 監視対象（トークンで特定するエージェント 1 件、または内蔵エージェント）ごとの検知、自ホストの情報、コマンドセットの定義、実行の指示と結果 |
| エージェントのローカル DB | `agent.db`（内蔵エージェントは `builtin-agent.db`） | データディレクトリ | `app/migrations/agentlocal` | 設定（接続先、トークン、独自 CA、インスタンス ID）、適用中の監視ルール、未送信の報告、走査の状態、配信されたコマンドセットの定義、コマンドセットの実行とスケジュールの状態 |

- 日時はすべて INTEGER の Unix 秒（UTC）で保存します。`0` は「未設定」を表します。画面、CLI、通知ではローカル時間で表示します。
- ファイルは実行ユーザーの所有で、umask 077 により `0600`（ディレクトリは `0700`）で作成します。既存のファイルとディレクトリの所有者と権限は変更も確認もしません。
- スキーマは goose で管理し、DB を開いたときに未適用のマイグレーションを自動適用します。セントラルは起動時にすべての監視対象の DB を開いて適用します。各 DB に goose 管理用の `goose_db_version` テーブルが作られます（アプリケーションからは参照しません）。
- モデルは 1 テーブル 1 ファイルで `app/models/<テーブル名>.go` に置きます。

## 1. セントラル管理用 DB（central.db）

### accounts

ブラウザ画面を使う利用者（アカウント）。モデル: `app/models/account.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |

| password_hash | TEXT | NO | - | パスワードのハッシュ（PBKDF2-SHA256、`pbkdf2-sha256$回数$salt$hash`） |

| language | TEXT | NO | 'auto' | ブラウザ画面の表示言語の設定（`auto`: ブラウザの言語から自動判別 / `en` / `ja`） |
| disabled | INTEGER | NO | 0 | 無効なら 1 |
| failed_logins | INTEGER | NO | 0 | 連続したログインの失敗回数 |
| locked_until | INTEGER | NO | 0 | ログインを受け付けない期限 |
| created_at | INTEGER | NO | - | 作成日時 |
| updated_at | INTEGER | NO | - | 更新日時 |

リレーション: sessions.account_id、auth_codes.account_id、browser_verifications.account_id から参照される（削除時は連鎖削除）

### tokens

エージェントの認証情報。エージェントの認証はハッシュで照合し、使用中の値は管理用の CLI で表示するために保存します（ブラウザには発行と再発行の直後を除き、略した値だけを返す）。モデル: `app/models/token.go`。

| --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |
| name | TEXT | NO | - | トークン名（一意。エージェントの識別名） |
| hash | TEXT | NO | - | 現在の値（`mmr_...`）の SHA-256（一意。認証の照合に使う） |
| value | TEXT | NO | '' | 現在の値（`mmr_...`）。発行、再発行、自動更新の値への切り替えで更新する |
| expires_at | INTEGER | NO | - | 現在の値の有効期限 |
| pending_hash | TEXT | NO | '' | 自動更新で渡した新しい値の SHA-256（未使用の間だけ） |
| pending_expires_at | INTEGER | NO | 0 | 新しい値の有効期限 |
| renew_counter | INTEGER | NO | 0 | 自動更新の回数（新しい値の導出に使う） |
| instance_id | TEXT | NO | '' | 結び付いたエージェントのインスタンス ID（エージェントが初期化時に作る値。空は未結び付け） |
| bound_at | INTEGER | NO | 0 | 結び付けた日時 |
| used_at | INTEGER | NO | 0 | 現在の値で最初に接続した日時（0 は未使用） |
| last_seen_at | INTEGER | NO | 0 | 最後の接続日時 |

| reissued_at | INTEGER | NO | 0 | 再発行日時 |
| renewed_at | INTEGER | NO | 0 | 自動更新の新しい値に切り替わった日時 |
| created_at | INTEGER | NO | - | 発行日時 |
| created_by | TEXT | NO | '' | 発行したアカウントのその時点のメールアドレス（`ctl` の操作は `cli`） |

## 2. 監視対象ごとの DB（targets/agent-&lt;id&gt;.db）
